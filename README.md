# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB712: Manage endpoint protection with Microsoft Intune and Defender
### Session description

Manage endpoint protection with Microsoft Intune and Microsoft Defender for Endpoint, including devices that aren't enrolled in Intune. In this hands-on lab, you'll onboard devices, enable configuration protection, assign safe deployment channels, review effective settings, and offboard your test devices.

### 🚀 Getting started

#### In a guided session

Open the [detailed lab instructions](instructions/README.md) and follow along with your instructor. The guide contains the steps and screenshots for each exercise.

#### On your own

Open the [detailed lab instructions](instructions/README.md) and complete the exercises in order, from configuring security settings management through offboarding your test devices.

#### For presenters

Use the [LAB712 introductory slides (PowerPoint)](docs/slides/LAB712-context-Ignite-2026.pptx), formatted with the supplied Microsoft Ignite template, for a short introduction. The deck includes context-setting slides and a talk track in the speaker notes.

Review the [presenter preparation and team responsibilities](docs/README.md) before delivery. Skillable environment availability and end-to-end rehearsal remain pending confirmation; the preparation checklist doesn't establish that the environment is ready.

The deck also includes internal preparation notes and source references, including a hidden preparation slide. Hidden slides and notes aren't a security boundary. Remove internal material before distributing the PowerPoint externally.

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- Configure Defender for Endpoint security settings management and onboard devices, including devices that aren't enrolled in Intune.
- Enable configuration protection and assign device groups to safe deployment channels through Intune.
- Verify effective security settings in the Microsoft Defender portal and offboard test devices.

### 💻 Technologies used

- Microsoft Intune
- Microsoft Defender for Endpoint
- Microsoft Defender Antivirus
- Windows
- PowerShell
